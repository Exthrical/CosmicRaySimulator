# Cosmic Ray Simulator

A browser-based Three.js visualization of high-energy primary particles and atmospheric cascades.

## Requirements

- Node.js 20.19 or newer

## Development

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. The application must be served over HTTP; opening `index.html` directly as a `file://` page will prevent its ES module graph from loading.

## Production build

```bash
npm run build
npm run preview
```

The build output is written to `dist/`.
